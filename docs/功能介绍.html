📱顾客端 — 扫码全流程

顾客无需注册登录，扫码即可完成从下单到评价的全流程。

进店扫大堂码
→
选项目 + 选技师
→
提交订单
→
客服派单
→
扫房间码看进度
→
服务完成评价

🏷️ 大堂码下单

顾客进店扫码，选择服务项目和心仪技师，提交订单后等待客服分配房间。

🚪 房间码跟踪

客服分配房间后，顾客扫房间码即可查看服务进度、加钟、提交评价。

🔐 免登录凭证

HMAC-SHA256 签名 Token，24 小时有效，自动持久化到 localStorage，刷新不丢。

👥 多顾客房间

大厅/包间/VIP 房间支持多位顾客同时使用，各自扫码查看自己的订单。

⭐ 评价系统

服务完成后顾客可直接评价技师，评分计入技师档案。

📶 实时推送

WebSocket 实时推送订单状态变更，顾客无需手动刷新。

🎛️客服派单台

移动端优先的派单界面，客服一键完成房间和技师分配。

📋 排队列表

实时显示所有待派单订单，按时间排序，支持筛选。

🎯 一键派单

选择房间和技师后点击"确认派单"，系统自动校验容量和技师状态。

🔄 排钟轮转

不指定技师时自动按轮转顺序分配，确保公平。

📊 状态看板

技师空闲/忙碌状态实时更新，房间占用情况一目了然。

排钟轮转机制：系统支持顺序轮排制，技师按 rotation_order 排序，每次派单后自动排到队尾。支持按等级、从业年限、明星标记等多维度排序。

👤技师管理

完整的技师档案管理体系。

📸 技师档案

头像、等级、从业年限、擅长项目、个人简介，支持照片上传。

⭐ 明星技师

标记明星技师，在顾客端优先展示，提升品牌形象。

📈 评分系统

顾客评价汇总为技师评分，支持 AI 评分和人工评分双轨制。

🎯 轮转管理

rotation_order / rotation_active / rotation_weight 精细控制轮转策略。

⚙️技术架构

🖥️ 后端

Node.js 22 + Fastify 5 + SQLite（better-sqlite3）
RESTful API + WebSocket 实时推送

🎨 前端

React 19 + Vite 6 + TypeScript 7
Tailwind CSS 3 + lucide-react 图标

📱 PWA

支持添加到主屏幕，离线缓存，移动端原生体验

🔒 安全

JWT 认证 + HMAC 签名凭证 + 按身份分桶限流 + SQL 参数化

限流策略：按身份分桶（员工 user:id / 顾客 guest:ticketId / 匿名 ip:addr），读写分离（读 1200/分，写 120/分），互不影响。
